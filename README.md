# Internet Limiter

Windows-приложение на C# (WPF, .NET 8) для ограничения скорости интернета отдельных программ.

## Возможности

- Список запущенных приложений с иконками, именами процессов и путями
- Установка лимита скорости (КБ/с или МБ/с) на выбранное приложение — применяется и к загрузке, и к отдаче
- Изменение и снятие лимита на лету
- Панель «Активные лимиты» — управление всеми установленными ограничениями, в том числе для незапущенных приложений
- Поиск/фильтр приложений

## Как это работает

Приложение использует встроенный механизм Windows — **policy-based QoS** (`NetQosPolicy`). Для каждого приложения создаётся политика `InternetLimiter_<имя процесса>` с условием совпадения по имени исполняемого файла (`AppPathNameMatchCondition`) и ограничением `ThrottleRateAction` в битах в секунду.

Политики применяются к **ActiveStore** — действуют сразу и сохраняются до перезагрузки системы (после перезагрузки лимиты сбрасываются). Лимит распространяется на все процессы с таким именем исполняемого файла.

## Требования

- Windows 10/11 или Windows Server 2016+
- **Права администратора** — приложение запрашивает их через манифест (`requireAdministrator`)
- .NET 8 Runtime (Desktop Runtime)

## Сборка и запуск

```powershell
cd src\InternetLimiter
dotnet build -c Release
.\bin\Release\net8.0-windows\InternetLimiter.exe
```

## Ограничения

- Лимит задаётся на имя исполняемого файла (`chrome.exe`), а не на отдельный PID — ограничиваются все экземпляры приложения.
- Если у разных приложений одинаковое имя exe, лимит применится ко всем.
- Для UDP-трафика входящее ограничение может работать не во всех случаях (для TCP — работает в обе стороны).
